
## 🌍 Conteúdo

Este repositório pode conter:

- Shapefiles, GeoJSON e outros formatos geoespaciais;
- Dados históricos georreferenciados;
- Scripts de processamento;
- Arquivos de visualização (HTML, JS, CSS);
- Documentação metodológica.

Os mapas interativos estão disponíveis no site principal do projeto.

---

## 🔄 Versionamento

Este projeto utiliza controle de versões via GitHub e atribuição de DOI por meio do Zenodo.

Cada **Release** corresponde a uma versão oficial do conjunto de dados.

- Versões anteriores permanecem disponíveis;
- A versão mais recente é sempre indicada no Zenodo.

---

## ⚙️ Requisitos (se aplicável)

Para uso dos dados:

- QGIS 3.x ou superior;
- Softwares compatíveis com formatos GIS;
- Navegador moderno para acesso ao webmap.

---

## 📜 Metodologia (resumo)

O projeto é desenvolvido a partir de:

- Levantamento documental e cartográfico;
- Georreferenciamento de fontes históricas;
- Organização em banco geoespacial;
- Produção do mapas interativo.
